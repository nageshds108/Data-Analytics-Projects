# Excel Project

## 📌 Project Overview
This project is an **interactive Excel dashboard** built to analyze the **Data Jobs market** across different job roles, countries, job types, platforms, and salary ranges. The dashboard enables users to explore **salary insights, job demand, job availability, and skill requirements** for data-related roles using Excel-based analytics.

The project combines **raw job posting data**, **data transformation**, and **visual dashboarding** to support **career-oriented and market analysis decisions**.

---

## 📂 Dataset Description
The dataset includes information such as:
- Job title and job category
- Job location and country
- Job schedule type (Full-time / Part-time / Remote)
- Salary (yearly and hourly)
- Hiring platform (Indeed, LinkedIn, ZipRecruiter, etc.)
- Company name
- Required skills (SQL, Python, AWS, etc.)

---

## 🗂️ Excel File Structure
The Excel workbook contains **three main sheets**:

### 🔹 `Data` (Raw Data Sheet)
This sheet contains the **original job postings data**, including job titles, locations, salaries, work type, platform source, and required skills.  
It acts as the **base dataset** for all calculations, pivot tables, and dashboard elements.

---

### 🔹 `Sub-Data` (Processed & Aggregated Data)
This sheet contains **derived and summarized data** created from the raw dataset.
- Median salary calculation by **job role**
- Job count distribution across **countries**
- Job posting counts by **platform (Indeed, LinkedIn, ZipRecruiter, etc.)**
- Sorted and structured tables used as **data sources for charts and slicers**

This sheet works as a **data preparation layer**, separating raw data from analysis.

---

### 🔹 `Project` (Dashboard Sheet)
This is the **main interactive dashboard** titled **“Data Jobs Dashboard”**.

It visually presents:
- Median salary by job title
- Job demand by country
- Job type distribution (Full-time, Part-time)
- Platform-wise job postings
- Role-based job insights

---

## 🛠️ How to Use the Dashboard
1. Open `Project1.xlsx`
2. Navigate to the **Project** sheet
3. Use the **filters and slicers** to:
   - Select a **Job Title** (e.g., Data Analyst)
   - Select a **Country**
   - Select **Job Type** (Full-time / Part-time)
4. The charts and metrics update **dynamically** based on your selection
5. Use the dashboard to:
   - Compare salaries across roles
   - Identify high-demand countries
   - Understand which platforms post the most jobs
   - Analyze full-time vs part-time opportunities
